| اللغة | عدد المفاتيح قبل | عدد المفاتيح بعد |
| :--- | :--- | :--- |

---

## 2. التغييرات المنفذة

تم إضافة 144 مفتاحاً إلى قسم `ar` في `i18n.js` لتطابق مفاتيح `en` بنسبة 100%.

---

## 3. سكربت التحقق التلقائي

تم إنشاء سكربت `scripts/check-i18n.js` يتحقق من تطابق المفاتيح ويُفشل البناء إذا كانت هناك مفاتيح مفقودة:

```bash
node scripts/check-i18n.js
```

**المسار:** `scripts/check-i18n.js`

لإضافته إلى pipeline البناء، أضف في `package.json`:
```json
{
  "scripts": {
    "prebuild": "node scripts/check-i18n.js"
  }
}
```
