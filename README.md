# اللجنة الطبية العسكرية - الواجهة الأمامية

## نظرة عامة

هذا المستودع يحتوي على كود الواجهة الأمامية لتطبيق اللجنة الطبية العسكرية، وهو نظام شامل لإدارة اللجان الطبية. يهدف التطبيق إلى تبسيط العمليات الطبية والإدارية داخل اللجان العسكرية، ويوفر واجهة مستخدم حديثة وتفاعلية.

## الميزات الرئيسية

*   **واجهة مستخدم حديثة:** مبنية باستخدام React و TailwindCSS لتجربة مستخدم سلسة وجذابة.
*   **إدارة اللجان الطبية:** أدوات لإدارة المرضى، الأطباء، المواعيد، والقرارات الطبية.
*   **تكامل مع API:** يتصل بواجهة برمجة تطبيقات خلفية قوية (love-api) لجلب البيانات ومعالجتها.
*   **نظام تسجيل دخول آمن:** يدعم تسجيل دخول الأطباء والإدارة.
*   **تخصيص الثيمات:** خيارات متعددة لتخصيص مظهر التطبيق.

## التقنيات المستخدمة

*   **React:** مكتبة JavaScript لبناء واجهات المستخدم.
*   **Vite:** أداة بناء سريعة لتطوير الواجهة الأمامية.
*   **TailwindCSS:** إطار عمل CSS لتصميم سريع ومتجاوب.
*   **Radix UI:** مكتبة مكونات واجهة المستخدم.
*   **Axios:** مكتبة لإنشاء طلبات HTTP.
*   **Express:** إطار عمل Node.js (يستخدم غالبًا لخادم التطوير أو بعض الوظائف المحددة).
*   **Cloudflare Workers:** (محتمل) يستخدم لبعض وظائف الواجهة الأمامية أو التوجيه.

## الإعداد والتثبيت

لإعداد المشروع محليًا، اتبع الخطوات التالية:

1.  **استنساخ المستودع:**
    ```bash
    git clone https://github.com/Bomussa/love.git
    cd love
    ```

2.  **تثبيت التبعيات:**
    ```bash
    npm install
    ```

3.  **تكوين المتغيرات البيئية:**
    قم بإنشاء ملف `.env` في الجذر المشروع وأضف المتغيرات البيئية المطلوبة (مثل `VITE_API_URL`).

4.  **تشغيل خادم التطوير:**
    ```bash
    npm run dev
    ```
    سيتم تشغيل التطبيق على `http://localhost:5173` (أو منفذ آخر).
